# Provenance

Where the code in this repository came from, so a change upstream can be
traced and a licence question answered.

## From an earlier private project by the same author

Some of this repository's core CPU and DOS modules began as a port from an
earlier, unpublished reverse-engineering project of the author's own (also
GPL-3.0; nothing here builds against its tree, and it is not public).

| Here | Changes from the ported source |
|---|---|
| `src/cpu/cpu.c`, `cpu.h` | Semantics moved to `x86_sem.h`; STI/MOV SS interrupt shadow; write tracking of translated bytes; `stop_at`; memory watch and tracing removed; faults leave IP at the instruction |
| `src/cpu/x86_sem.h` | Moved out of `cpu.c`, not changed; `IDIV` of `0x80000000` by -1 now traps instead of faulting the host |
| `src/machine/dos*.c`, `pc.c` | Split into DOS/BIOS and devices; extended for play (see architecture.md); DOS/BIOS later split by service (`dos.c` dispatch, `dos_memory.c`, `dos_programs.c`, `dos_files.c`, `dos_keyboard.c`, `dos_video.c`) |
| `tests/sstest.py`, `sst286.py`, `test186.c` | Paths made configurable |
| `tests/cpu_api.c` | Supplies the two machine hooks itself |
| `tools/unpack.py` | DLL path |
| `src/host/midistream.c`, `.h` | Include guard |
| `src/host/main.c` (`pc_scancode`) | The SDL-to-set-1 table |

`tools/fade_calibration.py` uses calibration routine locations and probe
design from that earlier project's own ISR probe. It assembles its own
wrapper using this repository's assembler and extracts the routines from the
user's installation; it has no dependency on the other project's files and
commits no original game bytes.

The bug tracker ([bugs.md](bugs.md)) restates that earlier project's own bug
catalogue, with citations to it under the name "Reimp" (the author's private
shorthand for it, not a published project).

## From DOSBox 0.74-2.1

GOG's install ships DOSBox's source (`DOSBOX/dosbox-0.74-2.1.tar.gz`, GPL-2
or later, compatible with this repository's GPL-3.0). The DOS this machine
provides follows it where the game can see the difference; the ports are
re-expressed in this code base, not copied files:

| Here | DOSBox source | What |
|---|---|---|
| `src/machine/dos_memory.c` memory allocation | `src/dos/dos_memory.cpp` | MCB chain: allocate (first/best/last fit), resize, free, free a process's blocks, compaction |
| `src/machine/dos_programs.c` `dos_load_program`, `make_env`, `psp_make`, `dos_terminate` | `src/dos/dos_execute.cpp`, `dos_classes.cpp` | EXEC sizing and placement, environment, PSP fields, entry registers, terminate |
| `src/machine/dos_files.c` INT 21h services | `src/dos/dos.cpp`, `dos_ioctl.cpp`, `dos_files.cpp` | Register results of 30h, 33h, 09h, 11h/12h (FCB find, volume label), 2Dh, 43h, 44h, 48h-4Dh, 52h |
| `src/machine/mouse.c` INT 33h | `src/ints/mouse.cpp` | Three buttons, X granularity, position set |
| `src/machine/pc.c` port delays | `src/hardware/iohandler.cpp` | Cycles per port read and write |
| `src/machine/pc.c` scanout | `src/hardware/vga_draw.cpp` | Four-part mode-13h draw timing, retrace display-address latch and chain-4 wrapping |
| `src/machine/pc.c` display palette | `src/hardware/vga_dac.cpp` | Triplet publication, changed-mask updates and alias colours |
| `src/host/audio.c` OPL gain | `src/hardware/adlib.cpp` | AdLib mixer `SetScale(2.0)` before clipping |
| `src/host/audio_mix.h` OPL interpolation | `src/hardware/mixer.cpp` | Equal-rate 14-bit interpolation remainder, arithmetic rounding before channel gain |

Values measured from a running DOSBox rather than read from its source -
the BIOS data area, the memory layout the shell leaves, the VGA register
sets after a mode set - come from `tools/fidelity.py`.

## Not in the repository, ever

The original executables and data, anything unpacked or decoded from them,
the recompiler's output (C derived from the original machine code), coverage
files, recordings and screenshots. All of it is produced from the user's own
copy into a work directory outside the repository.
